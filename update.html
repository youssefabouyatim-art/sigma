SIGMA – Mise à jour des données

Prépare le fichier chiffré data.enc à partir du nouveau fichier SIGMA (.xlsx). Rien n’est envoyé sur internet : tout se passe sur cet appareil.

1Choisir le nouveau fichier SIGMA
2Saisir le mot de passe de l’application
3Créer le fichier
4Mettre en ligne
  1. Ouvrir le dépôt sigma sur github.com.
  2. Ajouter un fichier puis Télécharger des fichiers.
  3. Choisir le fichier data.enc qui vient d’être téléchargé (il remplace l’ancien).
  4. Commit changes. Les collègues ont les nouvelles données à leur prochaine ouverture avec internet.
